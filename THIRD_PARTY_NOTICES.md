# Third-party materials

The MIT license covers the authors' software and documentation in this repository. R, the R packages and Python libraries retain their own licenses. Their names in installation instructions do not change those licenses.

Historical observations originate from Yahoo Finance. Raw observations, provider response payloads and the private input vintage are not included in this public code repository. Their reuse remains subject to the provider's terms and any applicable permissions. Expected hashes and schemas identify the input without granting data redistribution rights.

Files in `reference/` are study-derived forecasts, outcomes, aggregate indices and numerical summaries supplied for verification. They are identified as archived evidence, separately from newly generated results. Manuscript files, editorial correspondence and reviewer reports are not part of this software distribution.
